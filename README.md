# City’s Mobile Beauty Spa website preview

A responsive, multi-page website preview for City’s Mobile Beauty Spa. The supplied flyer informed the treatments, advertised prices, Johannesburg house-call details and telephone number. Its image is not included in the website.

## Pages

- `index.html` — Home
- `treatments.html` — Full treatment menu and prices
- `experience.html` — About the service and home-visit details
- `book.html` — Appointment request form

## Preview

Open `index.html` in a browser or run a local static server from this folder. The request form validates the required fields and shows a preview-only confirmation. It does not send or store client information.

## Email delivery when ready to publish

The site is set up for GitHub Pages. Pages hosts static files and cannot run a private server-side email sender. To deliver appointment requests, connect a form service such as FormSubmit to the owner email, then complete its initial email activation. The provider offers an AJAX endpoint that can keep the client on the booking page. Review its current setup instructions at:

- https://formsubmit.co/documentation
- https://formsubmit.co/ajax-documentation

The current preview intentionally has no email endpoint configured. Treat requests as unconfirmed until the owner checks availability and confirms any applicable call-out fee.
